# Glossary

- **`base_path`:** the setting that tells a client where a service is. After [#80](https://github.com/ga4gh/ga4gh-sdk/issues/80), it's the root of its API, such as `https://host/ga4gh/tes/v1`.
- **cloud-registry:** a GA4GH Service Registry of ELIXIR Cloud & AAI.
- **Conquest:** a WES implementation that serves WES 1.1.
- **DRS:** GA4GH Data Repository Service.
- **Funnel:** a TES implementation.
- **LS Login:** Life Science Login, the identity provider that issues the tokens used here.
- **proTES:** a TES gateway of ELIXIR Cloud & AAI. It takes tasks and passes them on to TES instances.
- **SDK:** here, the library and CLI of [`ga4gh/ga4gh-sdk`](https://github.com/ga4gh/ga4gh-sdk).
- **Starter Kit:** the GA4GH Starter Kit WES, used by a test job of the SDK. It serves WES 1.0.1.
- **TES:** GA4GH Task Execution Service.
- **TRS:** GA4GH Tool Registry Service.
- **WES:** GA4GH Workflow Execution Service.
